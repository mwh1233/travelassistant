关键设计说明

  • create_agent 底层是 ReAct 循环，但通过 StepConfigMiddleware 在每步动态替换 system_prompt 和 tools，实现状态机引导
  • Middleware 在 awrap_model_call 中拦截 LLM 调用，根据 current_step 从预加载配置中取对应 prompt（Jinja2 渲染）和工具子集
  • 状态推进通过 state_transition 工具实现：LLM 调用 select_destination_tool 等工具时写入 state，Middleware 下一步读到新的 current_step
  • 回滚工具（ALL_ROLLBACK_TOOLS）允许用户改主意时退回上一步，清除后续步骤的状态
  • 长期记忆通过 PG Store 按 namespace 隔离（("user_profiles", user_id)），Middleware 每步注入到 prompt
  • MCP 客户端单例 + best-effort 加载（asyncio.wait_for timeout=20s），单个外部服务挂了不影响 Agent 运行
  • SSE 用 astream_events v2 监听 on_chat_model_stream（token）和 on_tool_start（工具状态），后端累积完整消息，流结束后存 PG
  • 开发用 MemorySaver()，生产切 AsyncPostgresSaver（已实现单例+双重检查锁）
