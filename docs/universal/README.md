# universal · Agent 开发通用知识库

这里沉淀 **Agent 开发中跨项目、跨团队都成立的通用知识**——不是某个项目的实现细节，而是"下一个项目还会用到"的方法论、模式、清单和踩坑记录。

## 收录原则

| 应该收录 | 不应该收录 |
|---|---|
| 方法论、架构模式、设计取舍 | 单个项目的业务逻辑 |
| 可复用的流程、检查清单 | 一次性的排查过程 |
| 通用基准、公开数据、行业结论 | 未脱敏的内部数据、密钥 |
| 踩坑记录 + 根因 + 规避方式 | 只对某个版本有效的临时补丁 |

## 命名约定

- 一个主题一个文件，**文件名格式固定为 `{编号}-{层级}-{主题}.md`**（层级取 `地基` / `运行时` / `质量` / `交付` / `迭代`，如 `D14-交付-人机协作.md`）；全部平铺存放，不建子目录
- 每个文件开头写清**适用范围 / 前置知识 / 对标版本 / 最后更新**（页眉九字段，详见 `D01-地基-写作规范.md` §4.2）
- 文档内的结论尽量标注**可信度**（已验证 / 行业共识 / 待验证）
- 有争议的地方保留分歧，不要强行统一
- 编号、层级、边界以 `D00-地基-总纲.md` 为准；发现重叠先改 D00 的边界定义，再改文档
